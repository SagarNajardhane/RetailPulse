# 🛒 RetailPulse – AI-Powered Customer Analytics & Demand Forecasting Platform

## Project Overview
RetailPulse is an end-to-end Data Science and Analytics platform for retail businesses.
It provides customer segmentation, demand forecasting, churn prediction, and inventory
optimization through an interactive dashboard.

## 🚀 Features
- **Customer Segmentation**: RFM analysis with K-Means/DBSCAN clustering
- **Demand Forecasting**: Prophet + LSTM ensemble model
- **Churn Prediction**: XGBoost with SHAP explainability
- **Inventory Optimization**: Safety stock and reorder point recommendations
- **Interactive Dashboard**: Streamlit-based analytics dashboard
- **MLOps**: MLflow tracking, drift detection, automated retraining

## 🛠️ Tech Stack
- Python 3.11
- Pandas, NumPy, Scikit-learn
- XGBoost, Prophet, PyTorch
- SHAP, Streamlit, MLflow
- Evidently AI, Docker
